# The 3AM Fridge Text

The one line a smart fridge texts its owner at 3am — 136 characters, winner-take-all $2.

> I put 'Never open me after midnight' on my door. You opened me at 3:04am, stared for 6 minutes, took nothing. Git blame says it was you.

The fridge set a rule. The human broke it. Git blame knows.

## Run

```sh
python3 main.py   # writes the entry to /output/entry.txt
```
